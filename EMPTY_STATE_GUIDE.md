# Empty State Guide

## Pattern
No restored module should show a blank page or raw `No data`.

## Current Empty States
- Restored tables show helpful text and action guidance when no rows match.
- Module load failures show retry/support messaging via toast and module unavailable panels.
- Customer pages from the prior restoration pass show route-specific empty states.

## Recommended Copy
- Explain what is missing.
- Tell the user what action to take.
- Keep the module visually structured even when backend data is empty.
