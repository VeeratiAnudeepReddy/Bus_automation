# Chart Index

## Implemented Chart Cards
- `MiniAreaChart`: trend and bar-combination card using SVG.
- `DonutChart`: distribution card using CSS conic gradient and progress bars.

## Module Usage
- Finance: revenue and payment distributions.
- Payments: amount and status trends.
- Refunds: refund value trends.
- Pricing: rule value and approval trends.
- Coupons: usage and campaign distribution.
- Reports: metric distribution.
- Audit: event activity trend.
- Fleet: asset, maintenance, and fuel distribution.
- Super Admin: executive metric trend.

## Dependency Note
`recharts` is not currently installed. No package dependency was added in this frontend-only restoration.
