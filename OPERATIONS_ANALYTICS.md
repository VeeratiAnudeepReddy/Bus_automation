# Operations Analytics

## Metrics
- Fleet count
- Active buses
- Maintenance due
- Drivers and conductors available
- Trips today
- Running trips
- Delayed trips
- Cancelled trips
- Open incidents
- Fuel litres and cost
- Maintenance cost
- Revenue placeholder from ticket volume
- Average speed from GPS location updates
- Active trip count by live status
- Passenger occupancy from Trip.occupancy
- Driver/conductor action timelines from TripEvent

## APIs
- `GET /api/operations/dashboard`
- `GET /api/dispatcher/dashboard`
- `GET /api/trips/:id/history`
