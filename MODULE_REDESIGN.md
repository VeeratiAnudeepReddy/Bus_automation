# Module Redesign

## Restored Modules
- Finance Dashboard: KPIs, revenue/gateway/wallet/refund charts, transaction table, route collections, map card.
- Payments: payment center KPIs, status distribution, searchable payment table, detail drawer, payment detail page.
- Refunds: refund queue, approval/status KPIs, refund analytics, pending queue table.
- Pricing: fare matrix, rule analytics, approvals, simulator/new-rule action workspaces.
- Coupons: campaign dashboard, usage analytics, campaign builder, coupon detail page.
- Reports: executive analytics center with chart cards, export actions, and report table.
- Fleet: fleet command center with vehicle KPIs, maintenance queue, fuel/fleet charting, map card.
- Super Admin: platform console with finance, reports, audit, and payment oversight.
- Audit: audit log review with actor/event metrics and searchable table.

## Existing Modules Preserved
Customer, organization, operations, driver, conductor, dispatcher, ticketing, support, and onboarding routes remain connected to existing frontend APIs.
