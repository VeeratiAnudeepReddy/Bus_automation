# Drawer Components

## Implemented
`DetailDrawer` in `frontend/components/RestoredEnterpriseModules.tsx`.

## Purpose
Provides a consistent right-side panel area for:
- View.
- Edit.
- Timeline.
- History.
- Documents.
- Audit.
- Notes.

## Current Behavior
The drawer displays selected record context from existing API data and preserves full detail page links where available.
